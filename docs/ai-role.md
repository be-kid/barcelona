# OpenAI 역할 · 프롬프트 경계 · 비용

## AI는 무엇인가

**일정 편집 조수.**  
숙소·Day 테마·예약 확정 스팟은 이미 있고, AI는 빈 슬롯을 채우고 사용자가 말한 범위만 고친다.

```
사용자 고정 ──────────────► locked (숙소, Day 제목, 티켓 시간)
대화로 채움 ──────────────► draft  (점심, 카페, 사이 스팟, 팁)
OpenAI 출력 ──────────────► assistant_message + JSON patch
서버 ─────────────────────► locked 검사 후 적용
프론트 ───────────────────► 지도 핀/루트 갱신
```

## 시스템 프롬프트에 넣을 규칙 (요약)

1. 제공된 itinerary의 `locked: true`는 절대 변경하지 말 것  
2. 전체 일정을 다시 쓰지 말고, 요청된 day/slot만 patch  
3. 새 장소는 name, lat, lng, time, note, slot을 채울 것  
4. 좌표가 불확실하면 찍지 말고 `needs_clarification: true`로 질문  
5. 답변은 한국어 2~4문장 + patch  
6. 하루 places는 최대 5~6개 (optional 제외 시)

## 비용 감각 (여행 1건)

| 사용 패턴 | 모델 | 대략 |
|-----------|------|------|
| 20턴 디테일 채우기 | GPT-5.4-mini | **$0.05–$0.30** |
| 40턴 + 여러 번 되돌리기 | GPT-5.4-mini | **$0.20–$0.50** |
| 같은 양을 GPT-5.4 | GPT-5.4 | 약 3~5× |

절약 레버: Day focus, patch 출력, prompt cache, 장문 금지.
